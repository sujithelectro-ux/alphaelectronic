    Go-live checklist

    One-time Firebase Console steps for the admin and customer logins

    1. Publish rules: Firebase Console → Realtime Database → Rules → paste database.rules.json → Publish.
    2. Enable login: Authentication → Sign-in method → enable Email/Password, Google and Phone.
    3. Set the first admin: Realtime Database → Data → create config/adminEmail with your admin email as a string (or admins/UID = true). After that, use Admins in this panel to add or remove other admins.
    4. Authorized domains: Authentication → Settings → Authorized domains → add the domain you host the website on.
    5. Test: sign out, sign in again at login.html?next=admin.html, create an invoice and watch it sync.
